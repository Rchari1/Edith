Review what has happened in this session and save what will still matter later.

1. Look back over the conversation for: decisions and the reasoning behind them, non-obvious discoveries, gotchas that cost real time, conventions adopted.
2. For each, call `save_note` with a self-contained body that explains WHY, not just what. Write it so it reads correctly months later with no memory of this session.
3. Skip narration of what happened, anything reconstructible from the code or git history, and restatements of public documentation.
4. Reuse an existing note id when this session deepens something already captured, rather than minting a near-duplicate.
5. Report what you saved in one line each. If nothing durable came up, say so rather than inventing notes.
